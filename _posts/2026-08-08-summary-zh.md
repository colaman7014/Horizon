## [AMD 收購 Taalas 將 AI 模型直接蝕刻至矽晶片](https://www.theregister.com/systems/2026/08/06/amd-acquires-ai-chip-startup-taalas-to-boost-inference-performance-by-etching-models-into-silicon/5284344) ⭐️ 8.0/10

AMD 已收購位於多倫多的新創公司 Taalas，以開發能將 AI 模型權重直接蝕刻至硬體中的客製化矽晶片，目標是大幅加速推論效能並降低邊緣運算裝置的功耗。 此收購案顯示 AMD 正積極佈局硬體加速的 AI 推論市場，有望透過為消費性電子、機器人與物聯網應用提供高速度且低功耗的 AI 解決方案，徹底改變與 NVIDIA 及雲端服務供應商的競爭格局。 Taalas 的旗艦 HC1 晶片能以約 200 瓦功耗處理 Llama 3.1 8B 模型，達到每秒約 17,000 個 token 的速度，其推論效能比傳統 GPU 快上 48 倍，且能將模型權重直接硬線路化至矽基底中。

## [企業爭相降低 AI token 消耗以控制成本](https://simonwillison.net/2026/Aug/7/pdfs-are-terrible/#atom-everything) ⭐️ 8.0/10

Accenture 近期披露，非工程師員工因無效地將 PDF 檔案轉換為 Markdown 格式，意外推高了 AI API 支出。此案例凸顯出業界正積極尋求優化 token 消耗量，以遏制企業在生成式 AI 工具上的失控成本。 隨著生成式 AI 普及，未優化的 token 使用正威脅企業利潤率與雲端基礎設施的擴展能力。解決這些效率問題對於維持可持續的 AI 投資報酬率至關重要，也能防止科技產業面臨更廣泛的經濟壓力。 該案例特別指出，PDF 格式對 LLM 的解析極度低效，會在轉換格式時造成嚴重的 token 膨脹。優化輸入資料結構並實施嚴格的使用政策，已成為降低 API 延遲與控制月費的關鍵步驟。

rss · Simon Willison · 8月7日 16:18

**背景**: 大型語言模型（LLM）會將文字切割為稱為 token 的單位進行處理，這些單位通常是字元或單詞的片段。每向 AI API 發送一個 token 都會產生費用，雖然輸入 token 的價格通常低於輸出 token，但在大規模應用下仍會快速累積。當非技術人員運行自動化代理程式或批次轉換腳本卻未進行優化時，token 消耗量可能迅速失控，直接影響雲端供應商利潤率與企業預算。
